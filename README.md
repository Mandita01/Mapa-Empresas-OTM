# Mapa Empresas OTM

Projeto de apresentação visual para o mapa de empresas que aderiram ao sistema OTM, com foco em dados e visualização de indicadores em formato executivo.

## Visão geral

Este repositório reúne:
- a apresentação em HTML do mapa e indicadores;
- as imagens das telas principais do projeto;
- o arquivo de dados/Power BI utilizado na análise.

## Descrição

O objetivo do projeto é apresentar de forma clara e visual a distribuição das empresas que aderiram ao OTM, com foco em análise geográfica, indicadores e leitura executiva.
